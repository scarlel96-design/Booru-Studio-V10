# ADR 0022 — Design language synthesis instead of OS skin mixing

## Status
Accepted in Sprint 10.

## Decision
Use one Booru Studio token/interaction system derived from Apple hierarchy/craft, One UI reachability
and viewing-vs-interaction structure, and Windows familiar desktop navigation/settings IA. Do not copy
platform chrome or combine ornamental traits literally.

## Consequences
Feature QML consumes semantic tokens. Desktop density remains appropriate for mouse/keyboard while hit
targets and hierarchy stay accessible. Windows settings conventions remain the baseline mental model.
